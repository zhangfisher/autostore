# AutoStore Core

AutoStore 的核心是一个基于 Proxy 的响应式状态系统：状态对象被代理，"计算属性"自动追踪 getter 中读取的路径作为依赖，并在依赖变化时重新计算。本文档是该核心系统的领域词汇表。

## Language

### 观察对象与状态树

**计算属性 (Computed)**:
一个依据其他状态派生出的值。由一个 getter 函数定义，自动追踪 getter 中读取的路径作为依赖，依赖变化时重算。其结果可写回状态树（原位），也可仅保留在对象自身（游离）。
_Avoid_: 派生值、衍生字段

**关联 (Associated)**:
一个观察对象成为状态树某个路径上的节点。关联对象的计算结果**回写**到该路径指向的位置，并可通过该路径被监听。
_Avoid_: 绑定、挂载

**游离 (Detached)**:
一个观察对象不属于状态树，没有对应的状态节点，是与状态体系**完全割裂的外部观察者**。计算结果保存在对象自身，**不回写**状态树；其值变更不进入状态变更通知流，因此不可被其他观察对象声明为依赖，也不对全局状态监听可见——只能通过该对象自身的 watch 被监听。其 path 仅作为作用域与依赖解析的基准（锚点），不指向任何真实状态节点。通过动态创建（`computedObjects.create`）得到的观察对象始终游离。
_Avoid_: 独立、脱钩

**上下文 (Context)**:
观察对象在状态树中的所在位置，即它自身的路径、父路径、父对象与所在值。关联对象在状态树构建时自动获得上下文；游离对象默认无上下文，可在动态创建时通过 `anchor` 选项显式声明其逻辑位置——**仅用于**解析相对的作用域与依赖路径，不改变其游离性质，也不引发回写。
_Avoid_: 语境、环境

**锚点 (Anchor)**:
游离观察对象（如动态创建的计算对象）在创建时显式声明的逻辑位置（一条状态路径）。锚点仅作为相对作用域与依赖路径解析的基准，**不等于关联**——它不把对象挂载到状态树，也不引发结果回写。
_Avoid_: 上下文（"上下文"特指关联对象的完整位置）、挂载点

### 路径

**作用域 (Scope)**:
传入计算 getter 的第一个参数所指向的对象。可指定为整棵状态树、上下文所在对象、其父对象、或一条绝对/相对路径。
_Avoid_: 范围

**依赖 (Depends)**:
计算属性所读取、并据以重算的状态路径。同步计算自动收集；异步计算需手工声明。支持绝对路径与相对路径。

**绝对路径 (Absolute path)**:
从状态树根开始定位的路径。

**相对路径 (Relative path)**:
相对于上下文所在位置解析的路径（`./` 指当前对象所在容器、`../` 指父对象）。只有在具备上下文时才能计算。
