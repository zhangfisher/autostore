# `shallow(obj, deep)`：浅代理的深度参数化

## 背景

ADR-0006 的 `shallow()` 只有一档：仅根对象一层浅代理，成员读出即原始引用。这在「行级数据 bulk、
增删改整行可订阅」之外留下一个空档——**行内字段级订阅**。典型场景：万行表格只想对
`items.0.fieldName` 这一层做细粒度订阅与计算属性，而行内的嵌套对象（`row.meta.xxx`）体积大、
无需响应。此前只能二选一：整树深代理（放弃性能）或纯浅（放弃行内订阅）。

## 决策

`shallow()` 增加第二参数 `deep`（泛型 `Deep extends 0 | 1 = 0`，运行时参数 + 字面量类型推导）：

- **`deep=0`（默认）**：现状不变——仅根对象一层浅代理。
- **`deep=1`**：**根 + 成员两层浅代理**。成员属性读写有事件、成员内函数照常创建计算属性；
  **孙级及以下读出即 raw**，直接修改静默。「成员」指距根恰好一跳的属性/索引，对象根与数组根
  行为对称（`shallow(arr, 1)` 代理元素；`shallow({list}, 1)` 代理 `list` 本身、其元素属孙级仍 raw）。
- **标记值从布尔改为归一化数字**：`obj[SHALLOW_PROXY_FLAG] = deep > 0 ? 1 : 0`。品牌类型
  `ShallowObject<T, Deep> = T & { [FLAG]: Deep }` 与运行时戳完全对称，`ComputedState` 按
  `Deep` 分发到 `ShallowState<U, Deep>`（递减递归：`Deep=1` 时成员再做一层单层转换，孙级原样）。

三条边界决策：

1. **越界归一**：JS 调用方不受类型约束，运行时 `deep>0` 一律按 1。静默降级到 0 会砍掉调用方
   以为有的响应，比宽容归一更危险。
2. **双重身份全局语义**：同一 raw 对象既出现在浅子树内又出现在普通路径下时，以先建立的
   标记/代理为准（标记与 `proxyCache` 都按对象全局生效，不因路径分裂）。与 ADR-0006
   「值级标记而非路径声明」一脉相承。
3. **frozen 降级**：deep=1 的成员若不可扩展，惰性下戳静默失败 → 该成员走完全深代理。
   降级方向（浅→深）与 ADR-0006 对根对象的既有处理一致，是性能退化而非语义错误。

## 理由

- **成员浅代理而非恢复默认深代理**：若 deep=1 表示「成员起恢复完全深代理」，则运行时行为
  等价于不标记，API 失去存在意义。「成员浅、孙级 raw」是「行级可订阅、行内嵌套不管」的
  实用中间档。
- **取值仅 0|1、不推广 N 层**：两层覆盖了真实场景（行级订阅）；N 层泛化增加标记语义
  （剩余层数的传递与合并规则）与类型递归复杂度，当前无需求（YAGNI）。
- **惰性下戳而非急切预标记**：成员在首次经代理读取时才被下戳 `0`。急切方案需在标记时遍历
  大数组（与 shallow 的性能初衷相悖），且无法覆盖之后 `push`/`set` 进来的新成员；惰性方案
  让动态成员自然纳管，代价仅是读取路径上一次属性赋值。

## 备选方案

- **N 层泛化（deep=2,3,…）**：无现实需求支撑，标记传递/类型递归成本先行。否决。
- **成员恢复默认深代理（二元开关）**：运行时等价于不标记，deep=1 无独立语义。否决。
- **路径语义（同对象浅路径浅、深路径深）**：代理缓存键需加入深度维度，与「值级标记跟随
  数据走」决策相悖。否决。
- **急切预标记成员**：大数组全量遍历违背性能初衷，动态成员不覆盖。否决。

## 后果

- **已回填既有浅对象不受影响**：旧布尔 `true` 标记被读取时视为 0，行为与升级前一致；
  `isShallow()` 同时认布尔与数字（同页混布新旧捆绑副本场景，`Symbol.for` 全局注册使二者可互判）。
- **`ShallowObject<T, Deep = 0>` 泛型带默认值**，既有 `ShallowObject<T>` 写法不破；
  `ShallowState<T, Deep = 0>` 同理。类型调用方传非字面量 `number` 会因 `Deep extends 0|1`
  约束编译报错——须传字面量，属预期人体工学。
- **对象根 deep=1 且成员为数组时，数组元素（孙级）保持 raw**：类型层以
  `T[K] extends readonly any[] ? T[K] : ShallowState<T[K], 0>` 守卫，与运行时严格对齐。
  既有 `Deep=0` 数组根的元素函数映射行为（ADR-0006 遗留的宽松处）本次不动。
- **成员对象被写入一个 Symbol 属性**（剩余浅层数 0）：与根对象被 `shallow()` 盖戳同类，
  不进 `Object.keys`/`JSON.stringify`，序列化零污染。
- 性能定位：deep=1 的读取成本介于纯浅与完全深代理之间——只有成员一跳进陷阱，孙级读仍走
  原生路径。基准设施见 ADR-0006（`packages/core/bench/reactive-bench.ts`）。
