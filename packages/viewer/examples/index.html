状态树中的函数即同步计算属性（σ 图标）；异步计算使用 computed() 包装；markRaw 对象使用特殊图标并完整展开

通过 store-id 属性从全局注册表中查找并绑定 store

通过 store 属性直接绑定 store 实例

state 为 docker run 命令行参数，按功能分组；每个配置项均使用 configurable() 声明 schema（label / group / widget / choices / 校验 / icon 等），全部 31 个图标经 icon-url 从 iconify 批量拉取（仅一次合并请求）；本 viewer 设置 icon-modify="outline"，请求名自动追加 -outline 后缀（schema.icon 引用名不变），可用控制面板切换风格对比

各 widget 的编辑控件演示（需将控制面板「编辑模式」切到 click-edit 或 edit；Schema 显示默认生效，可勾选「禁用 Schema 显示」对比）：click-edit 下双击值进入编辑，编辑即时生效写入状态（无确认/取消）；值无效时控件下方实时显示红色错误且暂不写入，修正后自动写入并隐藏；Enter 前进到下一个可编辑节点；编辑在所有节点上生效——所有对象/数组容器（plainObject、withConfigurable、collapsedContainer、各分组）双击即进入 JSON 整体编辑，configurable 容器同样正常渲染子节点；edit 模式下叶子成员常驻编辑控件，Enter 在控件间转移焦点

图标注册链演示（slot 自定义 > 内置 > icon-url 拉取）：① user/box 引用 slot 自定义图标 custom-user/custom-box；② 本 viewer 覆盖内置 object/array 图标（同心圆/圆角方块），树中所有对象与数组节点即刻换装；③ home/star/settings/lock 四个未知名渲染时攒批合并为一次 iconify 批量请求；④ this-icon-does-not-exist 命中 not_found 负缓存，回落类型图标。本 viewer 同时设置 icon-modify="outline"：远程请求名自动追加风格后缀（home → home-outline），schema.icon 引用名不变
